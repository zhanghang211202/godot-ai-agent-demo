# C0：二職業のルール試作

2026-10-24 に作った、魔法使いと騎士の一戦ずつを試す独立した Godot の原型です。二職業の全機能や六つの構成の完成を意味しません。

`npm run game:classes` で起動します。魔法使いは数に限りのある火・水・風の元素を吸収して術式に変え、騎士は限られた金貨で武装を整え、長剣と徽記から重刃を作ります。盤面は 6×4 で、回転、方向による支援、実際の自動戦闘と攻撃元の確認ができます。戦闘前の状態は `user://class-prototype-run.json` に保存し、旧森林版とは分けます。

当時は魔法使い8種類、騎士4種類の道具、3配方、6種類の取得元で、固定の素材と敵を使用しました。種子は保存しますが、この試作で内容をランダム生成するものではありません。[当時の開発ログと実行画像](devlog/2026-10-24-class-rules.ja.md) · [ルール概要](class-prototype-contract.md)
