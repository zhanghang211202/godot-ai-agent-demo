# C0 双职业规则实验：首个可玩原型

交付日期：2026-10-24（JST）。状态：**可运行的原生Godot规则原型；不是C0全部退出条件、C1美术切片或六流派完整Demo**。长期范围见[需求](requirements.md)、[职业设计](classes-and-builds.md)和[开发计划](development-plan.md)，当前精确行为见[原型契约](class-prototype-contract.md)。

## 入口与实际范围

```powershell
npm run game:classes
```

新入口打开 `scenes/class_lab.tscn`。法师与骑士有不同的有限来源、准备动作、配方与攻击节奏；共用6×4布局、旋转、方向支援、一战模拟和来源复盘。界面是文字物件和法/刃/靶符号的规则示意，不含正式人物精灵和背景。默认 `npm run game` 仍运行原v0.3森林样板，其12装备/5配方/7祝福/5战及旧存档不变。

## 入门操作

1. 法师：点火元素，再点左上微光术式，编织焰爆；原本两格术式变成四格法印，会真实占用更多空间。
2. 把水元素放在第4列第3行，再把风叠在同一格，生成横向三格潮汐连枪。这里列/行从1开始；底层坐标是 `(3,2)`。
3. 将聚能晶核放在法印旁，观察方向支援；R改变待放方向，右键或Esc取消，取消不扣资源。
4. 骑士：开新骑士实验，点4金币的蓄势徽记叠到左上长剑，生成重刃；第二枚徽记放在第3列第2行，可连接重刃。两次购买后剩4金币。
5. 按空格或开始训练，观察自动施法/蓄势和伤害来源。结算后恢复战前，调整空间再训练；本实验没有五战奖励。

背包物件可点击后再点击格位，也可拖放。拖动中按R会更新实际落地方向。丢弃不返还原料、金币或来源；没有撤销。职业按钮写明“新实验”，点击会开启新的初始配置，未保存的当前配置随之结束。

## 保存与兼容

实验使用 `user://class-prototype-run.json`；文档标识为 `kind=class-prototype`、`schema_version=1`、`rules_version=1`。它与旧远征的schema 1是两个不同格式。默认入口不自动读档，点击读取实验恢复准备；战中退出后读取将回到开战前。来源领取次数、基础材料（含丢弃账）、金币花费和next_uid严格守恒，读取失败不改变当前配置。

默认旧 `user://emberpack-run.json` 继续由旧入口读写。实验拒绝将旧格式解释成法师/骑士，不迁移、不覆盖旧档；遇到未知、损坏或不支持格式也保留原文件。实验文件已有恢复用临时文件/备份时停止替换，不静默删除恢复资料。新保存路径也拒绝Windows尾点/尾空格与备用数据流别名。
