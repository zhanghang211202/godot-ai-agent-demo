# 多职业背包构筑 RPG 文档入口（新标题待定）

当前可玩版本为 **v0.3 森林美术样板（M1-A/B）**，沿用 v0.2 规则；没有新的职业系统。全量素材、教学、预览与撤销等未完成工作已按新需求重排。见[样板实际交付](iteration-03-sample.md)。

2026-10-23 后续决策：**背包仍是核心，不同角色有独立职业玩法、资源获取与背景，每角色至少三种构筑。初期魔法师＋H近战骑士，炼金术士后续。** [职业与流派设计](classes-and-builds.md)细化六条首批路线，机制仍待实现。16-bit fantasy / tactical RPG 角色细节是美术目标。[八案](art-style-exploration.md)与[离线对照页](concepts/2026-10-23/index.html)保留为早期概念探索；不再八选一。
