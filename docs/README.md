# Emberpack 文档入口

当前可玩版本为 **v0.3 美术样板（M1-A/B）**，沿用 v0.2 规则。全量素材、渐进教学、属性比较与撤销等 M1-C 工作尚未完成，不能将样板视作完整 v0.3。见[本轮交付](iteration-03-sample.md)。
