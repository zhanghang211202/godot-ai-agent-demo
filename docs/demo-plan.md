# 星火旅囊 / Emberpack：最初の遊べる Demo

この文書は v0.1 の範囲と当時の簡略化したルールを残すもので、現在の要件基準ではありません。v0.2 の変更は[0.2 の記録](iteration-02.md)、2026-10-21 以降の基準は[製品要件](requirements.md)、[開発計画](development-plan.md)、[美術仕様](art-direction.md)を参照してください。

## 目標

一回約五分、敵が五回登場するオリジナルのピクセルアート RPG で、「バッグの配置が自動戦闘の結果を変える」面白さを確かめます。『靠装勇者』の戦前の買い物、形によるマスの占有、回転、隣接強化、合成、自動戦闘を参考にし、タイトル、画面、人物と背景は独自に作ります。

## 初版の範囲

1. **準備**：6×4 のバッグ、四枠の店、金貨、更新、売却。ドラッグまたはクリックで配置し、R で回転。
2. **組み合わせ**：剣、長剣、盾、弓、薬草、薬、砥石、余燼石。同種・同品質を合成でき、剣と砥石から進化装備を作る。
3. **支援**：隣の砥石が武器を強化し、盾は防御、薬草は回復を提供する。道具の組み合わせが戦闘に影響する。
4. **戦闘**：装備ごとの待ち時間に応じて自動攻撃し、体力、ダメージ、攻撃、会心と回復を表示する。
5. **進行**：段階的に強くなる五回の敵と最後のボス、報酬、回復、クリア・敗北と再開。
6. **見た目**：独自の森林、旅人と怪物、道具アイコン、当時の中国語画面、操作案内とショートカット。

## 初版では後回しにしたもの

長期育成、ガチャ、ペット、複数職業、オンライン対戦、完全な装備図鑑、保存。まず限られた装備で配置と戦闘の面白さを確かめます。

## 受け入れ条件

プロジェクトを開いてメイン画面を実行でき、初期の装備を移動・合成できること。範囲外や重なりによって装備や金貨が失われないこと。購入に応じて金貨と店が変化し、配置が戦闘に影響し、戦況が分かること。五戦を通過でき、敗北後にも再開できること。ネットワークサービスなしで動くこと。

## 初版の簡略化

同種・同品質の装備、または配方に合う材料を重ねると即座に合成します。支援装備は上下左右の隣接を使い、長剣は二マスです。初版で分かりやすく配置を試すためのルールであり、参考ゲームの全装備の方向支援や正確な合成タイミングを再現したものではありません。
