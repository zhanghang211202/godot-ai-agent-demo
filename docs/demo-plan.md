# 星火旅囊 / Emberpack — 首个可玩 Demo

## 目标

用一局约五分钟、五波敌人的原创像素背包 RPG，验证「背包布局决定自动战斗结果」的乐趣。
参考《靠装勇者》的战前购物、形状占格、旋转、相邻增益、装备合成与自动战斗循环，使用原创标题、界面、角色与场景。

## 首版范围

1. **准备**：6×4 背包、四格商店、金币、刷新、出售；鼠标拖放或点选放置，R 旋转。
2. **构筑**：剑、长剑、盾、弓、草药、药水、磨刀石、余烬石；同种同级可合成，剑与磨刀石可进化。
3. **协同**：邻接磨刀石强化武器；盾提供防护，草药恢复，装备组合影响战斗。
4. **战斗**：装备按冷却自动攻击；可见的血条、伤害数字、攻击动作、暴击与恢复反馈。
5. **流程**：五波递进敌人和最终 Boss、胜利奖励、回血、通关/失败及重新开始。
6. **表现**：原创像素森林场景、旅人和怪物精灵、装备图标、中文界面、清晰的操作提示与快捷键。

## 本版暂缓

长期养成、抽卡、宠物、多职业、联机/PvP、完整装备图鉴与存档。先用有限装备验证构筑和反馈。

## 验收

打开项目可直接运行主场景。初始背包能移动与合成，越界/重叠不会丢失装备或金币。
金币和商店状态真实变化，背包布局会改变战斗能力，战斗具有可理解的实时反馈。
能够走完五波并通关，也能失败后重新开始；演示不依赖网络服务。

## 本 Demo 的简化规则

同种同级装备或匹配配方通过叠放即时合成；辅助装备采用四向邻接，长剑维持两格。
这是为首版上手与布局反馈设计的规则，不代表原作全部装备的方向性协同或精确配方触发时机。
