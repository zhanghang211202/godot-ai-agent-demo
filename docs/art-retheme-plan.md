# 職業ごとの背景と美術の計画

単に同じ人物の色を変えるのではなく、職業ごとに人物、武器、背景、素材と戦い方の違いを示します。共通の 6×4 の配置操作は維持し、見た目は魔法を紡ぐ盤面や武装を整える盤面として表現します。

魔法使い MA は月庭と天文回廊、騎士 KA は聖堂と長槍を外観の基準に選びました。ただし現在は魔法使いを優先し、騎士の新規制作は後回しです。各職業の三つの外観案と三つの遊び方は別の検証対象であり、画像を選んだだけで流派が完成したとはしません。[外観基準](character-baselines.md) · [職業と構成](classes-and-builds.md)

人物、武器、背景、盤面、効果を小規模な実機画面で確認してから広げます。生成画像の手足、顔、武器、輪郭、切れと一貫性を目視し、実際のゲーム画面とコンセプト画像を区別します。[美術方針](art-direction.md) · [実際の静止画試作](iteration-c1-static-art.md)
