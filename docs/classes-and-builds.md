# 职业与构筑设计：双职业初期目标

**当前执行范围 · 2026-10-27：** 用户明确先做法师、敌人、特效、道具与核心玩法，C2及新增骑士工作后置。[当前法师一战](iteration-mage-trial.md)只使用已实现的元素编织与两配方。下述每职业三路线是长期设计，本轮不扩展召唤、循环、盾反或连击，也不将它们当作法师切片的前置条件。

更新：2026-10-26（JST）。状态：**M-01与K-01有C0规则原型及C1静态画面；完整双职业六路线仍为目标**。本页细化[产品需求](requirements.md)与[开发计划](development-plan.md)；默认v0.3森林样板不含职业系统。规则边界见[C0记录](iteration-c0-rules.md)与[原型契约](class-prototype-contract.md)，当前画面见[C1静态样板](iteration-c1-static-art.md)，不能以一战原型代替六路线验收。

## 1. 已确定的产品方向

用户将此前的八套世界观探索扩展为长期的多角色游戏方向：**背包构筑仍是核心，不同角色具有不同职业、资源来源、合成方式、战斗特点和背景**。角色之间不能只是换立绘、物品名和伤害倍率。初期开发魔法师与 H 方案的近战骑士，每个职业至少形成三条可玩的构筑路线。炼金术士列为后续职业，不是初期第三名角色。

共享骨架继续使用 6×4 背包的空间规划、物件摆放与旋转、合成、方向协同和自动战斗。背包是统一的构筑概念；各职业可以用法术编织台、遗物整备盘、炼金工作台解释它的外观。主标题与角色姓名待定，不因 H 被选为近战方向就把整款游戏命名为《圣像余烬》。

2026-10-24用户已选择MA「月庭礼装」与KA「旌旗长枪」作为[外观基准](character-baselines.md)：法师保留紫发琥珀眼、宽帽层裙与月杖，骑士保留栗发高马尾、象牙金甲、红披风与长枪的成年女性方向。现已另绘月杖、长剑/重刃三张静态姿态并接入两套职业背景；精确色板、受控逻辑像素、透明边缘和逐帧动作仍待整理。外观三案与构筑三路线分别验收，静态接入不代表生产品质或完整C1过审。

“手搓强大魔法”暂解释为**战前由玩家选择并编织法术，战中按构筑自动施放**。这是为了延续现有自动战斗而采用的设计假设，不是用户已逐字确认的即时操作要求；后续若希望战中手动施法，必须另立交互与节奏原型。

## 2. 构筑共用约束

1. **每条路线改变决策。** 至少改变资源转换、空间布局、触发方式或输出节奏中的两项，不能把三种颜色的法术或三把数值不同的剑直接算作三流派。
2. **允许混搭，保留机会成本。** 不预先选择并锁死子职业；玩家通过实际持有的物件与连接形成路线。跨路线组合会竞争背包空间、有限材料、核心件位置或战斗资源，不允许把所有核心收益无成本叠加。
3. **职业来源可不同。** 魔法师不必购买完整装备：有限的环境吸收、战后元素回收和研究奖励可提供构筑材料；骑士可整备、回收或锻造武器遗物。商店只是可选的获取渠道。具体价格、配额与刷新规则要先在资源原型中验证。
4. **输入与产物都有账。** 吸收、拆解、编织、锻造、药水混合均需记录来源、消耗和产物。失败不得吞材料；空间不足须原子失败或在确认前给出合法落点，不能生成隐形仓库。
5. **战斗可解释。** 自动触发要能追溯到物件、法术、契约或防护来源。复盘能说明强法术、召唤、反击或连击为何发生，也能显示资源不足与未触发原因。
6. **不预设最终数值。** 本页不锁定新增 MP、元素容量、蓄势时长、召唤数量或配方价格。示例是待验证的规则形状，不代表已完成平衡，也不承诺无限装备与任意自然语言施法。

## 3. 魔法师：把收集到的材料变成施法逻辑

人物采用用户所选MA成年女性「月庭礼装」，以紫发、琥珀眼、宽檐帽、层裙与月形法杖为识别点。新绘月杖静态姿态和月庭背景已接入；星图/月光远景的运行取景、逻辑像素与动作继续细化。未来元素容器、法术结构与契约须有不同轮廓；当前背包仍是文字物件占位，后续用形状、图标和文字区分火、水、风，不能只靠颜色。

### M-01 元素编织

- **资源来源：** 从有次数或总量限制的场景元素源、战后残留和研究奖励获得火、水、风等基础元素；具体元素清单与来源表待原型确定。反复开关界面或重新读档不能重新吸收同一来源。
- **转换与核心动作：** 战前将有限元素与法术结构拼配成可执行法术，预览其代价、效果和占格，再确认编织。不同组合形成行为差异，例如集中爆发与多段分配；不是任意元素数量都自动成为更强法术。
- **背包决策：** 未使用元素也需有明确的容器/库存边界；成型法术、元素供应件和防护件竞争空间。堆积原料会挤压即时战斗力，合成大法术可能挤掉其他核心件。旋转与方向连接影响实际获得支持的法术。
- **战斗差异：** 少量成型强法术按条件与冷却自动施放，强调准备后的爆发和资源消耗；玩家在战中观察结果，不做即时拼词或按键搓招。
- **短板：** 过度追求大法术会缺乏前段输出和防护；元素供给或连接不足时出现施法空档。具体消耗是否跨战保留须在资源模型中定稿，不能默认为无限补满。
- **可验证验收：** 同一合法资源库存能得到两种行为不同的法术方案，预览与实战相符；材料消耗只发生一次，越界/空间不足无损失败；战斗与复盘显示法术来源及未施放原因。至少一条自然获取链能在完整初期流程中完成该路线。

**合法获取链示例（设计，非已验证掉落表）：** 章节内有限元素源提供基础元素 → 玩家吸收并占用对应容器 → 战后选择补足另一类元素的奖励 → 在背包中保留防护、腾出法术落点 → 预览并确认复合强法术 → 带着实际消耗后的资源进入下一战。此链必须由最终来源/奖励表支持，不能靠调试赠送材料成立。

### M-02 契约召唤

- **资源来源：** 契约碎片或契约奖励与有限元素支持共同提供召唤条件；契约入口必须来自正常流程，不能要求只有测试工具才会给出的召唤核心。
- **转换与核心动作：** 战前组合契约与支持件，选择以少量强召唤或多单位协同为目标；战中按契约规则自动生成召唤实体。契约、供给和召唤上限共同限制收益。
- **背包决策：** 契约本体和维持/强化件占用空间。保留更多契约会压缩本体法术、防护与资源容器；召唤实体不能因为不在背包内就成为零成本的额外输出。
- **战斗差异：** 伤害与支持效果主要来自可辨认的召唤来源，形成布置后持续运作的节奏。少量强召唤与多召唤的差异须由实体、触发或资源规则体现，不能只加两张装饰立绘。
- **短板：** 建立召唤阵容需要准备空间和资源，启动阶段本体可能较弱；触及上限或资源不足时必须解释新召唤为何未发生。具体承伤、目标选择、死亡和重新召唤规则仍待定义。
- **可验证验收：** 正常获取契约后能实际产生召唤实体；每个实体拥有来源与实例标识，其行为和贡献可复盘；资源不足/达到上限不会生成超额实体，也不会免费重置契约；暂停、倍速与重复加载不复制召唤物。与元素编织在背包结构、战斗来源与节奏上可辨认。

**合法获取链示例：** 初期奖励提供一份入门契约或可组合碎片 → 用已取得的元素支持契约 → 在背包中为契约与支持件让出位置 → 战斗自动召唤并支付既定代价 → 后续奖励选择扩展召唤或强化本体，接受不能两者兼得的取舍。

### M-03 奥术循环

- **资源来源：** 正常获得的基础元素与法术，配合可获得的回收/返还结构；“返还”只能来自已经支付的合格行为，不能凭空产生新的场外材料。
- **转换与核心动作：** 通过施法返还、元素回收和屏障支持建立可持续施法链。战前安排消费者与回收件的方向关系，选择效率、保护或短期爆发。
- **背包决策：** 回收件和屏障件占掉直接伤害法术的位置；更稳定的闭环应降低即时爆发或挤压备用元素。空间不足时必须拆掉部分循环，不能把循环收益作为全局免费被动。
- **战斗差异：** 相比元素编织的集中爆发，更重视连续施法、可控返还和本体防护。复盘需能区分支付、返还与防护贡献，说明续航从何而来。
- **短板：** 核心组件不齐时既缺伤害又缺资源；过度防护可能无法在时限内取胜。循环必须具有净消耗、上限、触发次数限制或其他有限性证明，具体选择在规则原型中确定。
- **可验证验收：** 同样合法初始资源下，循环构筑能产生可观察的续航差异，并付出伤害/空间代价；返还不重复支付、不增加场外材料；回收不能递归触发自身，长时间模拟的资源、事件数与屏障均有界，不能产生无限施法或永久无敌。

**合法获取链示例：** 正常获得基础法术 → 从研究奖励中选择回收结构而放弃爆发奖励 → 以现有元素完成一次合法编织 → 调整回收与防护连接 → 在战斗账本中验证先支付、后有限返还。不能先假定玩家已拥有全部循环件再称路线可用。

## 4. 圣匣骑士：用武装规模与触发节奏形成近战差异

采用 H「圣像余烬」题材及用户所选KA「旌旗长枪」成年女性外观：栗发高马尾、象牙金甲与绯红披风，代表器具为长枪。姓名、精确色值、专用源画布与动作尚未确定；脸、发束、甲胄分层和武器轮廓仍须在专用像素帧中达标。背包表现为整理武装与遗物的整备盘，不把“职业独立背景”等同于首期制作三份完全不同的大地图。

KA选择确定人物身份与衣甲，**不改C0重刃规则或既有存档**。K-01已有基于KA重新绘制的双手重刃静态持握，长剑起手也有独立姿态；显示按准备配置与战斗快照映射，无武器时显示待配标记。蓄势与命中逐帧动作尚未制作；长枪不能仅改标签冒充重刃，也不能据概念图宣称已有长枪动作/规则。武器适配与未来路线仍按实际来源、空间和战斗事件验证。

### K-01 重刃破阵

- **资源来源：** 从武装整备、战后回收、锻造材料和遗物奖励获得大武器与支持件；购买可以是其中一条渠道，不要求全职业都从同一四格商店买成品。
- **转换与核心动作：** 战前选择一把大武器和蓄势支持，通过锻造/合成提升关键重击。战斗中的蓄势和释放自动执行，不以玩家手速或即时蓄力按键为门槛。
- **背包决策：** 大武器和完整支持连接占据显著空间，会排挤副武器、盾牌与恢复物件。升级产物变大时必须先验证放置空间，不能把大武器缩成一格以免去取舍。
- **战斗差异：** 攻击次数少、单次结果清楚，强调蓄势后的重击窗口；需要专用动作和来源反馈。是否加入破甲、打断等新状态要另行定义，名称“破阵”本身不代表这些机制已存在。
- **短板：** 输出间隔较长，成型前和蓄势期间需要生存准备；堆叠爆发后可能缺少恢复与连续伤害。
- **可验证验收：** 合法获取与锻造链能构成完整重刃路线；大武器的占格与支持关系确实限制其他物件；自动蓄势/释放反馈与实际事件一致，暂停和倍速不改变战果；与连击路线在攻击节奏及布局上明显不同。

**合法获取链示例：** 起始武装包含可用基础近战武器 → 战后回收材料并选择大武器锻造分支 → 检查产物占格、移走副武器 → 用有限奖励强化蓄势或防护之一 → 以真实整备结果进入后续战斗。不可用调试造出最终重刃跳过空间与经济检验。

### K-02 盾誓反击

- **资源来源：** 从盾具整备、护具遗物和防护类奖励获得核心；防护触发条件须由实际物件与状态提供，不能只给角色挂一个不可见反伤倍率。
- **转换与核心动作：** 战前组合盾、防护与反击媒介；战中由合格的格挡/防护事件触发自动反击。格挡是待开发的新规则，不等同于现有样板的护甲或反伤。
- **背包决策：** 盾与防护支持占用武器和进攻强化的位置；增加反击覆盖率要牺牲主动输出，不能靠堆盾同时获得最高攻速与最高重击。
- **战斗差异：** 输出围绕敌方进攻和自己的防护事件产生，节奏响应敌方攻击。盾击、护体和反击各有可识别反馈，避免只看见敌人无来源掉血。
- **短板：** 对低频攻击或防护触发少的战斗，反击收益较低；过度防御仍可能超时。具体格挡概率/容量/耗用、护甲结算与受击顺序待规则原型确定。
- **可验证验收：** 一次合格防护事件按明确规则触发有限反击，复盘关联原攻击和防护来源；反击不再次触发反击、反伤或自身回收而形成递归；未发生格挡/防护时不得凭空反击。合法通关链和与重刃不同的空间代价都需验证。

**合法获取链示例：** 正常取得基础盾 → 选择盾誓核心奖励而放弃重刃分支 → 在背包中连接防护支持 → 根据下一战的实际攻击节奏决定保留反击或补充主动武器 → 战后能从来源记录确认该选择的收益与损失。

### K-03 连击追猎

- **资源来源：** 从轻兵器整备、连击结构与追击遗物奖励获得组件；同样需要可从正常章节取得的起步件与补全路径。
- **转换与核心动作：** 通过轻兵器和命中序列积累有限连击，在条件满足时自动追击；选择更多独立攻击源或更完整的单链支持。具体连击归属、断链和追击时机在事件原型中确定。
- **背包决策：** 多件轻兵器虽小，完整连击链仍需占用连接位置与支持格；把空间分给更多攻击源，就会减少防护和重武器位置。不能让轻武器享受全部重刃蓄势收益且没有代价。
- **战斗差异：** 多次较小攻击与有限追击形成连续节奏；不要求玩家战中连点。伤害统计须区分基础命中和派生追击，避免一团数字掩盖触发关系。
- **短板：** 小额多次伤害面对某些防护规则可能效率较低，且依赖连击条件；是否存在打断连击的敌方机制要另行定义，不在文案中提前宣称已有。
- **可验证验收：** 构筑能通过正常轻兵器获取链成型；命中计数、追击触发和复盘来源一致；派生追击不能无界地继续累计自身触发；在同一测试条件下能观察到与重刃不同的事件分布和空间布局，而不只比较总伤害。

**合法获取链示例：** 以基础轻兵器起步 → 通过正常整备取得第二攻击源或连击支持二选一 → 放弃大武器占格，调整方向连接 → 从后续奖励中补足追击核心 → 用合法资源完成轻兵器路线，而不是先给满装再展示高速攻击动画。

## 5. 后续职业：炼金术士

炼金术士利用材料、药水、容器与催化器形成职业差异。G「黄昏炼金室」可以作为视觉参考，背景和最终造型仍待该职业进入开发时确认。以下三条是后续设计约束，不是本轮待实现的首发内容。

| 路线 | 来源与转换 | 背包/战斗差异与短板 | 未来验收重点 |
| --- | --- | --- | --- |
| A-01 自我强化 | 正常采集/奖励取得药材和基础药剂，调配为自身使用的强化配方 | 强化剂、容器与主武器竞争空间；围绕有限强化窗口改变自身能力。过量代价、持续时间、叠加和消耗规则待定义，不能默认永久无代价增益 | 实际付出药剂代价，强化可追溯且有限；有限库存能支撑正常流程，不因反复进出战斗复制药剂 |
| A-02 药水混合 | 正常获得不同基底、试剂和容器，战前按明示配方组合 | 备料广度与成品空间相互挤压；组合改变自动释放的治疗/攻击/支持行为，不能只有药水颜色不同。缺基底或反应条件时不能免费合成 | 至少两类组合产生可观察行为差异；确认前显示投入、产物与占格，失败不吞料；混合/拆解不可无限套利 |
| A-03 催化投掷 | 正常药剂与催化材料组合成投掷用配方 | 以自动投掷、有限后续反应形成延迟收益；携带催化器会压缩即时恢复/自强化。持续区域、延迟反应、目标和同类叠加必须以后定义 | 投掷来源和反应链可复盘，有明确触发上限；在目标/区域规则确定前不宣称已支持持续地面区域、任意连锁或多人站位 |

合法获取链的后续模板为“有限药材来源 → 获得/选择基底 → 保留容器落点 → 预览配方并支付材料 → 自动使用并计入消耗”。各路线都要各自补充完整正常流程证据；一张混药界面原型不代表该职业完成。

## 6. 跨路线与跨职业边界

- **职业内混搭：** 魔法师可以用召唤保护元素编织，但契约、元素供给与强法术共同占空间；骑士可以用轻武器填补重刃空档，但要放弃部分蓄势或防护支持。验收至少展示一组混搭的实际得失，不能只展示六套预设满装。
- **职业间物件：** 是否共享恢复物、基础材料和遗物尚未定稿。职业专属资源/配方必须有明确可用性；非法装备不会被静默转成别的资源。跨职业技能混搭不列初期承诺。
- **成长与经济：** 先证明单局中资源可获取、可消耗、可失败恢复，再定义解锁与局外成长。初期不预设技能树、天赋点、无限刷取、全角色共用商店或额外付费货币。
- **背景与关卡：** 两名初期角色都要有身份、背景与物件的对应表现。先用各自的一战样板验证；完整章节可以复用关卡结构和共用技术，但不能只换一个角色立绘就声称已有独立背景体验。初期场景、敌人及内容数量要在原型后重新排预算。

## 7. 规则、事件与保存边界

以下为后续实现必须解决的设计工作，不表示已添加到 `EmberRun` / `EmberSave`。

| 边界 | 必须明确的内容 | 禁止省略的风险 |
| --- | --- | --- |
| 职业定义 | 稳定 `class_id`、显示名、资源来源、可用物件/配方、起始构筑、背景资产引用 | 用角色皮肤名称推断职业；依赖中文显示名作存档键 |
| 资源账本 | 元素/材料/药剂的拥有量、容量、来源已领取标记、支付/返还顺序、跨战保留规则 | 进出界面或读档刷新资源；把场内返还变成场外永久增殖 |
| 法术产物 | 稳定法术/配方定义、实际投入、生成结果、占格、可施放条件 | 只有效果文案而无执行规则；材料已扣但产物放不下 |
| 召唤实体 | 契约 ID、实例 ID、所有者/来源、上限、目标、存续/死亡/撤销、资源支付和结算顺序 | 把召唤当额外无来源伤害；重复加载复制实体；未定义目标却假定能替本体挡伤 |
| 战斗事件 | 原事件与派生事件的来源链，基础攻击/法术/召唤/反击/追击分类，有限触发规则 | 返还触发返还、反击触发反击、追击触发自身的无界递归 |
| 新状态 | 屏障、格挡、强化、持续区域等分别定义是否存在、叠加、消耗、到期与清理 | 因技能名字或概念图就声称已有状态；沿用旧护甲公式假装已做格挡 |
| 复盘 | 各来源伤害/防护/消耗与返还，未触发原因，召唤贡献归属 | 用总 DPS 隐藏资源失败与错误触发；把模拟夹具当正常获得链 |

当前存档为 schema 1，仅保存整装/奖励阶段，战中退出后回到战前检查点。新职业版拟提高 schema 版本，并增加 `class_id`、职业规则版本、职业资源、来源领取标记、编织/契约状态与职业内容版本。准确字段与版本号以迁移实现为准，不在本轮直接修改存档格式。

**兼容方案：** 保留合法 schema 1 旧档的物件稳定 ID、随机序列、整装/奖励状态和原规则语义。建议将其识别为 `legacy` 远征，以旧规则继续或另开新职业远征；不得静默改成圣匣骑士、删除旧物件或补送新职业资源。若后来选择显式映射到新职业，必须先定义完整映射、预览结果与备份/回滚，再增加单独迁移验收。未知 schema、未知职业、非法资源或内容版本不匹配时给出恢复选项，并保留原档，不覆盖成一个新局。

新职业版继续优先采用战前检查点：保存契约与待用资源，战斗恢复时从检查点重新构造临时召唤实体、冷却和事件队列；不得同时恢复上场残留实体再免费召唤一遍。哪些召唤状态跨战保留、资源何时正式扣除，要在资源规则定稿时明确，并验证整装/奖励重载、战中退出、取消开始和保存失败等边界。

## 8. 切片顺序与完成验收

第一切片可以只制作 **M-01 元素编织 + K-01 重刃破阵**，以小规模真实交互证明两个职业的资源、背包、战斗、背景和保存路径确有差异。它是双职业系统样板，**不等于完整初期双职业交付**。

完整初期的硬条件是 **2 个职业 × 每职业至少 3 条路线 = 至少 6 条可玩路线**。路线定义可以迭代，但减少路线、把炼金术士算成初期角色、或以三套纯数值变体充数，都需要重新修订需求。旧样板的 12 物件 / 5 特殊配方 / 7 祝福 / 5 战只是当前实现与纯视觉回归预算，不能假定足以覆盖六路线；新职业池、配方和背景量须在规则原型后核算，未完成前不得写为已经支持。

| ID | 完整初期验收 | 证据要求 |
| --- | --- | --- |
| CB-01 | 两名可选角色具有不同资源来源、构筑动作与背景表现 | 用实际游戏操作和运行截图展示，不用概念图代替；说明共用与专属部分 |
| CB-02 | M-01/02/03、K-01/02/03 共六路线可分别从正常初始状态构筑 | 每路线记录可复现种子、获取/奖励选择、消耗和布局，并完成初期章节；不用调试加钱、送物或只靠预装测试场景 |
| CB-03 | 每路线在空间、资源或触发节奏上有清楚取舍，至少一组职业内混搭可用 | 对照布局、战斗来源与失败原因；一次固定种子通关只能证明可达，不能宣称六路线已平衡 |
| CB-04 | 元素编织与所有合成准确支付、放置并显示结果 | 覆盖不足材料、来源耗尽、越界、空间不足、取消与保存失败；失败不丢物、不复制资源 |
| CB-05 | 召唤、返还、反击与追击事件均有界且能追溯 | 正常触发、资源不足、触及上限、派生事件、暂停/倍速和长时间模拟检查；附精确结果与仍未覆盖的规则 |
| CB-06 | 新职业整装/奖励保存、战前恢复与旧档兼容成立 | schema 1 真实旧档、坏档、未知职业/版本与资源边界；保留备份，验证重载不复制资源和实体 |
| CB-07 | 两名角色都达到详细像素目标并能在真实尺寸中读懂动作 | 大像素角色图与专用战斗精灵分别验收；两职业各有主角/背景/UI/一战实机样板，概念图不作为动作完成证明 |
| CB-08 | 流派机制与入口可以通过教学、详情和复盘理解 | 职业专属操作有引导，材料/上限/触发条件显示准确，文本不宣传尚未实现的状态与敌人机制 |

当前已有M-01/K-01的有限资源取得、组合、一战与独立保存原型，以及三姿态和两背景的静态接入；**完整职业与六路线验收仍未完成**。下一步美术先整理逻辑像素、透明边缘、背景取景和真实动作；规则侧验证其余四路线与最小支持矩阵。旧档仍用legacy入口，不把本轮显示接入当作已实现保存迁移，最后按完整初期条件验收。
