## 騎士の武器と既存ルール

KA の長槍と赤い旗は人物を見分けるために残します。実際の戦闘姿勢は装備と構成に合わせます。C0 は長剣で始めて重刃を鍛造するため、**KA の顔、髪、鎧、配色を保った長剣と重刃の静止姿勢を別に描きました**。準備中は実際の配置、戦闘中は開戦時の配置を表示し、攻撃武器がない場合は未装備を示します。KC に人物を入れ替えたり、重刃のダメージを長槍と呼び直したりはしていません。

長槍の正式な攻撃と専用ルールは今後の設計・検証対象です。この選択では長槍の道具、命中、射程、状態を追加していません。将来の剣盾や軽武器も同じ KA の人物として器具と動きを作ります。魔法使いの月の杖は共通の外観として残し、元素の組み合わせ、召喚、循環は実際のルールイベントに合わせて姿勢と効果を設計します。

## 当時の成果と次の制作

1. 1122×1402 の静止姿勢三枚と 2172×724 の背景二枚を別に描いて組み込み、実際の一戦には C0 ルールを使用。表示範囲は alpha≥128 の領域を基準にし、足元を地面に合わせ、元 PNG は変更しない。
2. 色、ピクセルのまとまり、透明な色縁、比率を整理する。指示した8倍の論理グリッドは実現しておらず、現在は縦横比を保った最近傍の非整数倍率を試している。96×128／128×160 は比較候補であり、元 PNG の寸法を確定仕様とはしない。
3. 三つのウィンドウサイズで顔、武器、体力、6×4 盤面の文字を確認し、背景の下側によって月や建物の上部が切れる問題を改善する。武器の余白、足元の基準点と表示サイズも揃える。
4. 静止画の基準を満たした後、待機、攻撃・施法、受撃、退場の連続した姿勢を作り、一戦の既存イベントへ接続する。標的と文字の道具にも専用の美術が必要。

RV-02 の品質要件は引き続き修正が必要です。RV-03 には新しい姿勢、背景、ウィンドウの一部の静止画証拠がありますが、元画像の密度、透明な縁、背景の見せ方が自動的に承認されたわけではありません。RV-04 には施法・攻撃の四姿勢と一時停止・倍速の一部の証拠がありますが、待機の繰り返し、受撃、退場は未完成です。縮小比較や選択時の表示はコンセプト確認用であり、ゲーム実行の証拠と分けます。

入口は `npm run game` が森林試作、`npm run game:classes` が C0 ルールを使う C1 四姿勢試作、`npm run art:review` が六案の比較画面です。`EmberRun`／`EmberSave`、道具 ID、旧保存、6×4 の操作、旧試作の12／5／7／5という予算は互換性を保ちます。六流派、美術、動きの今後は[開発計画](development-plan.md)を参照してください。
