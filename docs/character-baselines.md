## 骑士武器与既有规则的适配

KA的长枪与红旗保留为人物展示的重要识别。实际战斗持握要匹配装备与构筑：当前C0原型仍是长剑起手、锻造重刃；接入该路线时，以**KA的脸、马尾、衣甲与配色另画持重刃姿势**。不直接换成KC整个人物，不将重刃伤害事件改名冒充已经实现的长枪机制。

长枪的正式攻击动作及专属规则仍待设计验证；这次选择没有新增长枪物件、命中、射程或状态。以后剑盾／轻兵器路线也以同一KA人物身份制作相应器具与动作。法师的月杖则作为共同人设器具，元素编织、召唤与循环按各自真实规则事件设计姿势与效果。

## 下一段可审查交付

1. 根据选定特征整理两份统一角色设定，归纳色阶与主要像素簇，保留可辨的脸、发型、衣甲和器具。
2. 分别重画专用战斗静态帧，先比较96×128／128×160候选源画布。记录源尺寸、人物头脚占高、武器包围盒、面部像素、透明边距与脚底锚点；这些尺寸仍是制作试验。
3. 各制作一段职业背景与连续地面，接到真实6×4职业布局，检查1280×800、1440×960、1920×1080中的人物、武器、生命条与中文正文。
4. 静态样板通过后制作真实待机／攻击或施法／受击／退场动作，再接入两职业各一条路线的一战切片。

选定人设不自动通过RV-02的全部品质要求，RV-03需要新的专用源帧、背景和实际窗口证据。现有缩小观察与本轮选定展示仍是静态概念审稿fixture。

当前启动入口仍为：`npm run game` 森林样板，`npm run game:classes` C0规则实验，`npm run art:review` 静态人设审稿台。`EmberRun`／`EmberSave`、稳定物品ID、旧存档以及现有6×4交互和12／5／7／5旧样板预算保持兼容。完整六路线、背景和动画的实现状态继续见[开发计划](development-plan.md)。
