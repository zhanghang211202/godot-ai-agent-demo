## 要望と、参考画像から読み取ったこと

ユーザーは、配置・回転・合成・方向付き支援・自動戦闘を残しつつ、バックパック以外の設定と新タイトルを求めています。今回提供されたローカルの二枚のキャラクター比較画像を実際に開き、特に **02 / 16-BIT FANTASY** と **08 / TACTICAL RPG** を確認しました。

魔女の目と表情、分かれた髪束、布・革・金属の層、戦術 RPG キャラクターの高いポニーテールと長柄武器などを品質の方向として抽出しました。元のピクセル寸法や色数、制作技法を測定したわけではありません。3.5〜4.5頭身、96×128 / 128×160 の戦闘用画布は今後の比較候補であり、参考画像から得た実測値ではありません。

前回の64×64キャラクターは、入力・比例・足元アンカー・アニメーション接続を検証した技術サンプルです。そのまま今回の完成品質の基準にはしません。透明な余白だけを広げても顔や髪の表現は増えないため、大きなピクセル立ち絵と専用の戦闘スプライトを別々に設計します。

## 判断と計画の変更

要件・開発計画・美術仕様・開発ノートを新要望に揃え、[換設定計画](../art-retheme-plan.md)を追加しました。優先順序は **M1-R：設定選択 → 同じ題材の主人公三案 → 新しい主人公・背景・UIと一戦の実機サンプル → M1-Cの全量制作と操作改善** です。

RV-01〜RV-06 に、人物の顔・髪・素材・姿勢・武器、実際のウィンドウ、アニメーション、盤面と既存ルールの互換性を確認する条件を記載しました。設定はユーザーの選択を待ち、任意の案を完成方針へ昇格させません。正式な名前は設定選択より後でも構いません。

保持する範囲は6×4、12装備・5特殊配合・7祝福・5戦です。`EmberRun` / `EmberSave` と安定した物品IDは内部互換用に残し、見た目の改造だけで保存形式を変えません。MP、自由遊泳、接線ゲーム、農業タイマー、時間ループの進行などは今回の題材から自動的に追加しません。

## 観察できた問題と対処

生成された大立ち絵は最終戦闘用より細長く、背景と金縁も細部が多くなりました。画像は方向の比較に限定し、戦闘キャラクターをそのまま切り抜いたり縮小したりして「完成スプライト」とは扱いません。小さい戦闘用の輪郭を別途描き直し、人物の後ろの模様と光を整理する必要があります。

画像内の格数・占有形・接続線は実際の配置規則を保証していません。価格、MPなどの文字や数値も生成上の構図用です。これらを実装済み機能と読めないよう、文書と比較ページに境界を明記しました。実装時には本来の6×4、物品形状、実際の支援対象に合わせて再制作します。

文書を最初にPowerShellの既定エンコーディングで表示した際、CJK文字が文字化けしました。UTF-8を明示して読み直すと正常で、元ファイルが壊れた現象ではありません。日本語と中国語を含む編集にはUTF-8を保つパッチを使いました。

ユーザーから預かった参考原画像とそのGodotインポートファイルは公開対象に含めません。今回生成したコンセプトは `docs/concepts/2026-10-23/` に置き、実機スクリーンショット用の不変フォルダーや過去画像を上書きしませんでした。ブログ草稿にも経緯と概念画像の区別を追記しました。

ブラウザーでは八画像のデコード、既定A/C比較、左右選択、カードからの単独・左右表示、左右キーと末尾からの循環、フォームフォーカスの保護、ピクセル表示、再読み込み後の初期化を確認しました。320pxと390pxの横あふれは0です。デスクトップ1425×2491の全体キャプチャと390×844の首画面も開いて確認しました。

これらは**コンセプト比較ページのブラウザー検証**です。独立したブラウザー設定とキャッシュ、キャプチャ、生の結果JSONは無視対象の `.tools/gallery-review/` に保持し、通常利用のブラウザープロファイルを使わず、追加依存もインストールしませんでした。実際のタッチ端末、スクリーンリーダー、Firefox、Safariは未検証です。

ブラウザー確認の初稿では、PowerShellのパイプを通した中国語の比較と、意図的に隠している読み上げ用領域を通常テキストと同じ基準で扱った判定から3件の誤報が出ました。ASCIIの判定式と可視領域の検査へ直して全22項目を再実行し、ページ本体の修正なしで成功しました。これは検証側の修正です。

ゲームコード、実行アセット、保存処理を変更していないため、今回は `npm run game:test` を再実行していません。前回の949項目は2026-10-22の実装確認結果であり、本日の新規実行結果には数えません。新しい絵のGodot接続、三種類のウィンドウでの実機表示、アニメーション、Windowsエクスポートや他プラットフォームは今回の検証対象外です。

## 次の工程と残る制限
