# 中国語文書の日本語整理

ユーザーから、翻訳が難しい文書は削除してもよいとの依頼を受けた。残っていた要件、開発計画、美術、職業、アニメーションの文書は、現在の優先事項と実装・未実装の境界を残した日本語の概要に整理した。過去の試作説明は、日本語の開発ログと版別画像を参照する短い文書にした。以前の中国語の詳細文を一文ずつ翻訳したものではなく、重複や古い詳細は省いている。二つの過去ログにあった中国語の引用・説明も日本語にした。

世界観八案と人物六案の比較ページは、日本語の説明と左右の選択欄を持つ簡潔なページに作り直した。画像そのものや版別の実行画像、画像の manifest、外部プラグインとライセンスは変更していない。新しい比較ページは旧ページの詳細な比較機能すべてを再現するものではなく、各側の切り替えと元画像の表示を残している。画像内の英語や、過去の検査結果・生成指示を記録した JSON にある元の名称は翻訳していない。

検証では Markdown のローカルリンク505件を確認し、欠落0、コードフェンスの不整合0。二つの比較ページについて、JavaScript の構文、画像ファイル14件、左右それぞれの初期表示と切り替えを確認した。ローカルブラウザーでも両ページの画面を見て、人物ページの左側を MA から MB へ変更し、画像リンクと表示が切り替わることを確認した。`git diff --check` は成功。ゲームのコードや素材は変更していないため、今回はゲームの実行テストを行っていない。
