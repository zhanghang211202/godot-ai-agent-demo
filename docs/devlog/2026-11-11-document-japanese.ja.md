# プロジェクト文書の日本語化：第一段階

README、MCP の設定説明、文書一覧、魔法使い優先計画、初版 Demo・v0.2・v0.3 の記録、キャラクター外観基準、素材の出典を日本語にした。`.codex/config.example.toml` の説明コメントも変更した。ゲームのルール、画像、外部プラグイン、フォントのライセンス本文には手を加えていない。

機械翻訳を試したところ、Markdown リンクの記号やゲーム固有の用語が変わる問題を確認したため、その結果は採用せず、元の内容を確認しながら書き直した。今回の9文書について、参照するローカルファイルの欠落0件、元文書のリンク先の削除0件、コードフェンスの不整合0件。設定例は TOML として読み込め、`git diff --check` も成功した。文書のみの変更のためゲームの実行テストは行っていない。

要件、開発計画、美術仕様、職業設計、歴史的な実装記録と二つのコンセプト比較ページなど、まだ中国語の文書が残っている。この段階を日本語化の完了とはしない。
