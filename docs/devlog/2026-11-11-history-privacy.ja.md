# 公開履歴の個人情報を整理

ユーザーの承認を得て、公開 `main` の履歴を隔離コピーで書き換えた。過去の作者・コミッターのメールを GitHub の no-reply アドレスに置き換え、確認できた本機パスと MCP の個別ルートを履歴のテキストから除いた。リポジトリの既存の他のローカル参照は公開対象に含めていない。

書き換え前後で公開履歴は69コミット。変更後の全コミットの作者・コミッターを確認し、対象メール、パス、個別ルートの変更履歴とコミットメッセージへのパターン検査は0件だった。Git の `fsck --full --no-reflogs` に問題はなく、最新コミットのファイルツリーは変更前と同一だった。リモートの更新は、書き換え前の先端を指定した `--force-with-lease` で行い、その後ローカルの `main` と追跡ブランチを同期した。未コミットのシーン変更はそのまま残した。

古い開発記録や画像 manifest には、当時のコミット ID を証拠として書いた箇所が残る。履歴の書き換えによりその ID は新しい公開履歴上の ID と一致しない。画像 manifest は過去の証拠として書き換えていない。GitHub のキャッシュや他の人の複製・フォークまで消去されたことは確認できない。
