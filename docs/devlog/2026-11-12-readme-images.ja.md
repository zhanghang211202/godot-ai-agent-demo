# README の画像を日本語画面に整理

ユーザーから README 内に中国語の画像があると指摘を受けた。旧職業試作の静止画と旧森林版の画面には中国語が表示されていることを目視で確認し、README から画像を外した。旧版の GIF も README から外し、中国語の画面を含む可能性がある古い動画への直接リンクも削除した。旧画像と動画の全フレームを新たに検査したわけではない。元の画像・動画と版別の開発記録は変更していない。

代わりに、既存の魔法使いの日本語画面から配方帳と六戦目の準備画面を追加した。既存の準備画面と合わせ、README に残した3画像を目視し、表示文字が日本語であることを確認した。いずれも Godot の自動操作による撮影として説明している。

README 内の3画像と Markdown のローカル参照を確認し、参照先の欠落は0件。`git diff --check` は成功した。文章と画像参照のみの変更で、ゲームの実行や保存への変更はない。
