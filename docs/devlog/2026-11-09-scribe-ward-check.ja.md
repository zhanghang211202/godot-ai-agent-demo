# 2026-11-09：符弾の有盾・無盾の実画面

書霊の符印を追加した後、初期装備の護符を残す場合と通常の廃棄操作で外す場合を、実際の第四戦の戦闘として確認した。fixture は独立した準備盤を作り、保存を無効にして第四戦へ移した試験で、最初から連戦した記録ではない。

![初期護符あり。三段に各2軽減](screenshots/2026-11-09-scribe-ward-check-v1/ward.png)

![初期護符なし。三段に軽減なし](screenshots/2026-11-09-scribe-ward-check-v1/no-ward.png)

両方とも2.4秒の実攻撃を撮影した。護符ありはダメージ9・軽減6、なしはダメージ15・軽減0で、盾の表示も前者だけ。無盾の場合は符印が人物の体付近に重なるが、顔は覆わない。人間の連続プレイや全解像度での視認性は未検証。

`game:mage:scribe:test` は19項目、失敗0。三段の実イベント、盾の有無、ダメージと軽減、独立エンジンとの一致、一時停止中の演出停止、画像保存と実プレイヤーセーブ不変を確認。Godot MCP の `script-validate` は1ファイル、エラー0・警告0。MCP が最初は接続拒否だったためプロジェクト内 SDK でエディターを再起動し、接続後に再検査した。起動時のプラグイン C# ビルドはエラー0、非推奨 API の警告3件だった。
