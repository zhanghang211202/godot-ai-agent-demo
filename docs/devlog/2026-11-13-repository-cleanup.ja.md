# 2026-11-13：公開前の整理

ユーザーの依頼で、Git 管理対象のファイル、画像の重複、ローカル設定と個人情報の混入を確認した。ゲーム、開発記録、ブログと各版の画像の関係を調べたうえで、完全に同じレシピ画面が二つの画像フォルダーに存在することを確認した。後の版の重複を削除し、README、ブログとその版の manifest は先の版の同一画像を参照する。二つのファイルの SHA-256 は同じで、残した画像を編集していない。約0.58 MiBを削減した。

ローカルの Codex 信頼設定についての個別事情を MCP 設定文書から外し、実際の設定ファイルは Git に含めない旨を残した。ローカルの SDK、エディター、キャッシュ、プレイヤーの保存、ユーザー提供の非公開の参考画像は Git 管理外のままとした。開いているエディターによる主シーンの未コミット変更には触れていない。

確認した範囲では、Git 管理対象のプロジェクト文書と設定に既知の形式の秘密鍵、代表的なアクセストークン、個人用メールアドレス、個人用の絶対パスは見つからなかった。Git 履歴の作者・コミッターのメールはすべて GitHub の no-reply ドメインだった。これらはパターン検索であり、未知の形式の秘密情報まで完全に検出したことを意味しない。

重複調査は10,000バイト以上の Git 管理ファイルを SHA-256 で比較し、同一内容は今回の一組のみだった。開発画像は作業ツリーで約326 MiBあり、大半は異なる版の記録だったため残している。Git の履歴や過去に削除したファイルも今回書き換えていない。ローカルの Git パックは調査時約638 MiBで、今回の重複削除だけで履歴全体が同じ量だけ小さくなるわけではない。

画像一覧を照合したところ、旧 `mage-swing.png` の manifest に記載された SHA-256 の一部が誤っていた。実ファイルから再計算した値に直し、画像自体は変更していない。
