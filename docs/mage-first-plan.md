# 魔法使い優先：月庭の一戦試作

**2026-11-07 更新：** その後、ユーザーから魔法使いの五戦とボスを要望されました。この文書の一戦は過去の段階です。五戦と魔力の残滓は[五戦の記録](devlog/2026-11-03-mage-campaign.ja.md)、専用の保存は[保存の記録](devlog/2026-11-07-mage-campaign-save.ja.md)を参照してください。さらに後の七戦版は[七戦の記録](devlog/2026-11-10-mage-seven-battles.ja.md)に記載しています。

決定日：2026-10-27（JST）。ユーザーは C2 と騎士を後回しにし、魔法使い、敵、効果、道具、基本の遊びを優先するよう依頼しました。これは、それまで二職業を同時に進める予定だった作業順に代わる範囲です。将来の六流派と五戦の要件は残しますが、この時点では拡張しません。

目標は、**元素を取得 → 限られた場所に配置 → 魔法を作る → 結晶核で支援 → 自動戦闘 → 結果を見て調整**という流れを理解して遊べるようにすることです。まず、魔法使いと月庭の敵一体で一戦を完成させます。

| 順序 | 当時の実施範囲 | 確認方法 |
| --- | --- | --- |
| 1 | 魔法使い専用の入口と独立した準備チェックポイント。騎士の旧入口を維持 | シーン、保存の分離、既存職業の回帰 |
| 2 | 木製標的を月庭の衛兵の四姿勢に変更。練習用の体力140、基本ダメージ8、攻撃間隔1.8秒を維持 | 姿勢、接地、実際の攻撃と命中を確認し、ルール上の結果を変えない |
| 3 | 既存の八種類の道具に専用アイコンを用意し、盤面、取得元、詳細画面に表示 | 縮小時の見やすさ、回転と占有マス、名前と絵の対応 |
| 4 | 微光、爆炎、潮汐、敵の星の攻撃に、それぞれコードで作るピクセル効果を追加 | 実際のイベントと連動し、三段攻撃と撃破時の途中終了、一時停止と速度を確認 |
| 5 | 配置と合成のプレビュー、開戦前の術式・支援値、実際の待ち時間と発動元を表示 | プレビューが実操作と一致し、資源を消費しないこと。待ち時間はルールの状態を参照 |
| 6 | 実際の勝敗と配置を比較し、日本語の記録と版別の実行画像を残す | 限られた資源での通常操作、プレイヤーの保存が変わらないこと、検査とアップロード |

以上の初版は実装済みです。内容、検査、制限は[初版の記録](iteration-mage-trial.md)にあります。初版は一戦、固定数の元素、二つの配方で、森林版の保存、既存の道具 ID と職業ルールのバージョンとの互換性を保ちました。

その後、要望に応じて[魔法使いの拡張](iteration-mage-expansion.md)を実装しました。実際にダメージを軽減した時だけ見える法盾、二種類の新しい敵、四種類の魔法、六つの配方を追加しています。当時は三体から一体を選ぶ一戦でした。後の五戦と固定報酬は冒頭の記録を参照してください。この拡張時点では召喚、循環、騎士の流派、ランダムな資源は未実装でした。

[エフェクト第二版](iteration-mage-vfx.md)では、短い線の演出を溜め・曲線の飛行・命中・残光に分け、小さなピクセル模様、連続した軌跡、前後の重なり、画面端の処理を追加しました。戦闘の数値は維持しています。合成成功の表示、魔法使いの受撃時の移動、キャラクターに追従する法盾の衝撃、三敵の予行演習は[後続の記録](devlog/2026-11-02-mage-rehearsal.ja.md)を参照してください。当時、施法・命中音と敵ごとの対処方法の充実は今後の課題でした。

美術は選択済みの MA の特徴と月庭の背景を使い、主人公の外観選びを繰り返しません。新しい敵と道具は実行用に作った候補であり、コンセプト比較画像を切り取って完成素材として扱うことはできません。主人公の元画像のピクセル格子と専用の受撃・倒地姿勢は未承認で、この段階で美術全体の受け入れ完了とはしていません。
