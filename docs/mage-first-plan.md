# 法师优先：月庭一战切片

决定日期：2026-10-27（JST）。用户明确：“C2可以先不用管，骑士也先不要管，首先做法师、敌人、特效、道具、核心玩法”。这是当前执行范围，覆盖此前要求双职业同步推进的阶段顺序。长期六路线和五战需求保留，当前不扩展。

目标：让玩家看懂并玩到**取得元素→安排有限空间→编织法术→连接聚能晶核→自动战斗→复盘后调整**，先交付法师与一个月庭敌人的完整感受。

| 顺序 | 本轮实施范围 | 验证方式 |
| --- | --- | --- |
| 1 | 专用法师入口与独立准备检查点；骑士保留旧入口 | 法师场景、保存隔离、原职业回归 |
| 2 | 月庭巡卫四姿势替换木靶；沿用当前训练敌人的140生命/8原始伤害/1.8秒攻击 | 姿势、接地、真实攻击与命中，不改变规则结果 |
| 3 | 八种现有物件的专用图标，进入背包、来源与详情 | 缩小可读性、旋转/占格、名字与道具对应 |
| 4 | 微光、焰爆、潮汐与敌方星辉攻击的独立代码像素效果 | 来自实际事件，三段数与致死截断对应，暂停/倍速一致 |
| 5 | 非破坏性的放置/编织预览、战前法术/协同数值、实际冷却与来源高亮 | 预览与真实操作一致且不扣资源；冷却读取规则状态 |
| 6 | 实际胜负与布局对照，日语记录和不可变运行截图 | 有限正常操作、玩家保存不变、相关检查与上传 |

以上首版已接入，实际内容、检查和限制见[本轮交付](iteration-mage-trial.md)。当前只做一战、固定有限元素和现有两条配方；不新加召唤、循环、骑士路线、五战奖励或随机资源。默认森林存档、现有物品ID和职业规则版本保持兼容。

美术：沿用已选MA身份和月庭背景，不重复主人公换装。新敌人和道具图集是专为运行绘制的候选，不能将概念比较图切成生产精灵。主角源网格与专用受击/倒地帧仍未过审，本轮不据此声称完整美术验收通过。
