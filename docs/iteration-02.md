# Demo 0.2：让布局与旅程产生更多选择

本轮延续首版的森林像素风格，重点增加背包构筑的可读性和一局远征中的成长。

## 范围

- 长剑占三格；增加焰纹大剑、荆棘木盾、逐风猎弓、浓缩暖心药，五条异物合成配方。
- 磨刀石仅强化左右装备，旋转后改为上下；显示生效格与连接，布局变化直接反映到属性。
- 前四场胜利后获得三选一祝福，选择后再进入下一轮商店。
- 准备与战利品阶段自动保存；旅途菜单支持保存、继续、读取与确认重开。
- 图鉴翻页、装备品质与合成空间提示、战况和敌人提示同步更新。

## 验收

1. 三格装备的移动、旋转与合成不会穿过其他装备或越界。
2. 磨刀石旋转确实改变生效方向，预览和实际伤害一致。
3. 祝福只能领取一次，未选择不能进入下一波，效果能改变战斗能力。
4. 保存并读取后背包、金币、关卡、祝福、商店和随机序列一致；损坏存档不破坏当前旅程。
5. 打开帮助或菜单会暂停战斗；测试与截图模式不读写真实存档。
6. 全部自动检查通过，实际画面可读，完成后推送到原仓库。
