# Demo 0.2：配置と遠征の選択肢を増やす

初版の森林ピクセルアートを引き継ぎ、バッグの組み合わせの分かりやすさと、一回の遠征中の成長を改善しました。

## 範囲

- 長剣を三マスに変更。焰紋の大剣、茨の木盾、逐風の狩猟弓、濃縮した回復薬と、五つの異なる材料による配方を追加。
- 砥石は左右だけを強化し、回転後は上下を強化。対象のマスと接続を表示し、配置変更を能力値に反映。
- 最初の四戦の勝利後、三つの祝福から一つを選んで次の店へ進む。
- 準備と報酬の段階で自動保存。旅のメニューから保存、続き、読み込み、確認付き再開が可能。
- 図鑑のページ切り替え、装備の品質と合成スペース、戦況と敵の情報を更新。

## 受け入れ条件

1. 三マスの装備を移動、回転、合成しても、他の装備を通過したり盤面の外に出たりしない。
2. 砥石の回転で支援方向が変わり、プレビューと実際のダメージが一致する。
3. 祝福は一回だけ取得でき、選ぶまで次へ進めず、効果が戦闘能力に反映される。
4. 保存・読み込み後にバッグ、金貨、戦闘、祝福、店、乱数の順序が一致し、破損データが現在の遠征を壊さない。
5. ヘルプまたはメニューを開くと戦闘が止まり、テストと画像撮影は実際の保存を読み書きしない。
6. 自動検査が通り、実画面が読みやすく、完成後に指定のリポジトリへアップロードする。
