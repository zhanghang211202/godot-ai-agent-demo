# Godot のアニメーション調査と改善

この文書は、以前の調査と実装結果を日本語で整理した概要です。現在は魔法使いを優先します。動きの改善は戦闘ルール、実際の発射・命中時刻、保存データを変えない表示上の変更として扱います。

## 調査で確認した構成

| 項目 | 確認した内容・場所 |
| --- | --- |
| プロジェクト | Godot 4.7、C#、GL Compatibility。確認した実行環境は Windows の Godot 4.7.2 .NET とプロジェクト内 SDK。`project.godot`、`scripts/godot.mjs` |
| シーン | 旧メインは `scenes/main.tscn`。魔法使いの遠征は `scenes/mage_campaign.tscn`、旧一戦は `scenes/mage_trial.tscn`。画面と戦闘の多くは `scripts/classes/class_lab.gd` から作られる |
| キャラクター | 魔法使いの画像は身体と杖が一体の姿勢画像。連続する身体の中間フレームや、骨を付けられる身体・腕・杖の独立レイヤーはない。既存の四姿勢は連続アニメーションの完成を意味しない |
| 描画と効果 | `scripts/classes/class_arena.gd`、`class_motion.gd`、`class_feedback.gd`、`mage_effects.gd`、`mage_shield.gd` と `class_actor.gdshader` が表示、効果、受撃色などを担当 |
| MCP | `addons/godot_mcp/` に [Godot-MCP](https://github.com/IvanMurzak/Godot-MCP) を導入。ローカル接続と確認の範囲は [MCP の記録](devlog/2026-11-02-mcp-connection.ja.md)、[設定](../MCP_SETUP.md)を参照 |

## 推奨する構成

既存の `Sprite2D` / `Node2D` と `AnimationPlayer` を組み合わせ、表示を動かす専用の子ノードやラッパーを使います。盤面やアリーナが毎フレーム位置や倍率を書き込む部分と、アニメーションが同じプロパティを取り合わないようにします。実際の発射、命中、ダメージ、一時停止、再生速度はゲームのイベントと時間に合わせます。

`AnimatedSprite2D` への移行は必須ではありません。元の四姿勢はそれぞれ足元や武器の位置が異なるため、単純に等分して切り替えるとずれます。骨格アニメーションも、現在は身体や杖の独立した素材がないため採用していません。新しい中間姿勢や分割素材は、別途制作して確認する必要があります。

## 第一段階の PoC と実装

2026-11-02、`scenes/components/mage_hit_motion.tscn` の独立した AnimationPlayer で受撃時の短い移動を作りました。既存の実際の敵攻撃イベントで動き、同時の多段命中は一つの反応にまとめます。一時停止と倍速に追従し、法盾と発射位置も移動に追従します。五つの位置を0.22秒で戻す表示であり、新しい身体の姿勢、ダメージ、命中時刻は追加・変更していません。[実装と検証](devlog/2026-11-02-mage-rehearsal.ja.md)

この PoC の実装時には MCP が接続できなかったため、プロジェクト内の Godot ツールで作業しました。後から MCP で作成したとは扱いません。

## MCP と AnimationPlayer の確認

2026-11-03、ローカル MCP を通じてシーンと AnimationPlayer を確認しました。受撃アニメーションは0.22秒、位置トラック1本、キー5個でした。メモリ上の複製のキーを変更して戻し、Godot API を MCP 経由で読み書きできることを確認しました。製品のアニメーションファイルへの変更保存、追加の Animation Tools 拡張、ゲーム実行時の MCP エラー収集は、この確認では検証していません。Codex セッションにツールが自動表示されなかったため、独立したローカル MCP クライアントを使いました。[実測記録](devlog/2026-11-03-mcp-mage-analysis.ja.md)

その後、`scenes/components/mage_cast_timeline.tscn` の AnimationPlayer で既存の姿勢と発射を接続し、MCP からトラックとキーを読み取りました。シーン自体は通常のプロジェクト編集で作成しています。[施法の同期](devlog/2026-11-03-mage-cast-sync.ja.md)

## 現在の動きと今後

魔法使いの遠征と試練は、待機から各術式の施法まで同じ四姿勢の杖の画像を使います。不自然だった全身の傾きや追加の中間姿勢は使わず、振り上げから発射姿勢へ切り替えます。発射と実ダメージの時刻は変更していません。[現在の動き](devlog/2026-11-12-mage-four-pose.ja.md)

今後新しい姿勢を作る場合は、顔、髪、手足、杖の長さとつながり、足元、表示サイズを目視し、実際の戦闘で連続再生を確認します。見た目だけの補間や自動テストだけで、自然な動きや人体の品質が完成したとは判断しません。
