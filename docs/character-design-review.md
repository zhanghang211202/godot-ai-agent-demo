# 二職業のキャラクター案：六案の比較

2026-10-24 に魔法使い三案（MA・MB・MC）と騎士三案（KA・KB・KC）を比較し、ユーザーは **MA と KA** を選びました。MA は広いつばの帽子、重なった服、月の杖、KA は栗色のポニーテール、明るい鎧、赤い布と長槍が特徴です。[選択した外観の基準](character-baselines.md)

六枚は外観を比較するための生成コンセプトで、実際の戦闘画像、完成した動き、三つの流派の実装ではありません。顔、目、髪、手、武器のつながり、縮小した輪郭、装飾、透明な縁と余白を確認する必要があります。戦闘に使う素材と背景は別に制作・検証します。[六案の一覧](concepts/2026-10-24-characters/index.html) · [当時の比較と制限](devlog/2026-10-24-character-studies.ja.md) · [選択の記録](devlog/2026-10-25-character-selection.ja.md)
