# v0.3 / M1 ネイティブアートの実装サンプル

このフォルダーは **M1 全素材完成版ではなく、主役＋苔団＋短剣・盾・砥石の動作確認用サンプル** です。既存ゲームや参考動画の画像は収録していません。元の v0.2 素材も上書きしません。

原本は `scripts/visuals/pixel_art_v03.gd` に手順と座標を記述した、プロジェクト独自のピクセル画です。PNG は同じコードから再生成した出力です。ゲームはコードから生成・キャッシュした Texture を実際に使用しており、PNG は資産レビューと将来の差し替えのための共通インターフェースです。

- `characters/hero_sheet.png` と `slime_sheet.png`：64×64 のフレームを 256×256 に配置。行順は idle / attack / hurt / defeat、各行は 4 / 4 / 2 / 4 フレーム。hurt 行の末尾 2 コマは透明。足元の基準点は `(32, 58)`。主役は右向き、苔団は左向き。
- `items/inventory/`：短剣 32×64、盾 64×64、砥石 32×32 の専用シルエット。回転時は画像全体を 90 度回し、縦横を引き伸ばしません。
- `items/icons/`：同じ 3 品の 32×32 サムネイル。短剣はサムネイル専用の斜め構図です。
- `previews/sample_contact.png`：人物 2 倍と装備原寸の資産比較画像です。
- `previews/animation_contact.png`：64×64 の原画を最近傍で **3 倍** にした比較画像です。上 4 行が主役、下 4 行が苔団。各ブロックの行順は idle / attack / hurt / defeat、列順はフレーム 0〜3。ゲームの実行画面ではありません。
- `manifest.json`：サイズ、ピボット、向き、クリップ、出自、SHA-256 と未置換の資産を記録します。
- `environments/forest/stage.png`：512×144、地面 y=126 の原生コード背景です。原本は `scripts/ui/forest_stage.gd`。描画レイヤーは一枚へ合成され、視差は未実装です。広い中間サイズでは静かな森林部分を延長し、元画像の範囲外を読まないようにします。

## 未完成範囲

残り 9 品の背包画像は **legacy_placeholder** です。32×32 の旧アイコンを正しい占有サイズの透明キャンバス中央に置きます。比率は保ちますが、専用の長剣・弓・薬瓶シルエットはまだありません。狼・ゴブリン・樹型敵も旧 96×96 静止画を使用する placeholder で、樹型は既存の `boss` テクスチャと同じです。主役に装備ごとの着替えレイヤーはなく、新しい燃焼・敵能力・戦闘ルールも加えていません。

## 再生成

プロジェクトルートから、プロジェクト内 SDK・キャッシュを設定するラッパーを使います。

```powershell
node scripts/godot.mjs play --headless --script res://scripts/visuals/export_art_v03.gd
```

ラッパーは起動後すぐ戻ります。出力完了は `.tools/logs/game.log` の `EmberArtV03 export: 9 assets, 0 failures` で確認します。アートの契約検査は `tests/test_art_v03.gd` です。プレビューは資産接触表であり、ブログ向け実機スクリーンショットは別途 `docs/devlog/screenshots/` に保存します。
