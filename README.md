# 月庭の魔法使いの試練（開発中・正式タイトル未定）

日本語の画面で遊べる、自動戦闘ゲームの試作です。新しい魔法使いの遠征では、戦う前に元素や魔法を並べ、全七戦に挑みます。魔法の組み合わせは16種類。勝つと魔力の残滓を手に入れ、次の戦いに使う素材へ変えられます。七戦目はボスです。

勝利後は体力が全回復し、配置と残りの資源は引き継ぎます。敗北した場合は同じ戦いの準備からやり直せます。準備中の変更、勝利後の次の戦い、最終クリアの状態は専用のファイルに自動保存され、再起動時に読み込まれます。戦闘中に終了した場合は、その戦いの準備から再開します。

敵は月庭の衛兵、鏡翼の蛾、茨の石像、月灯の精霊、星詠みの書霊、星巡りの蛇、最後のボス・月冠の星守の七種類です。新しく追加した敵は一枚の姿勢画像を使い、浮遊や受撃時の動きで表現しています。連続した姿勢画像によるアニメーションは今後の課題です。[七戦の記録](docs/devlog/2026-11-10-mage-seven-battles.ja.md)

新しい遠征では敵が順に強くなります。従来の五戦版と一戦版の数値は変えていません。魔法使いには一つの待機姿勢と三つずつの攻撃・防御姿勢があり、攻撃や防御のたびに姿勢が選ばれます。AnimationPlayer は実際の発射・命中に合わせて動き、施法中の受撃は攻撃姿勢を優先します。道具の待ち時間や自動戦闘のルールは変えていません。[動きの記録](docs/devlog/2026-11-12-mage-seven-poses.ja.md)

画面にはプレイヤーに必要な操作を表示しています。自動保存に失敗した場合は「保存を再試行」と表示されます。戦闘の試算機能は開発テスト用として残しています。[画面の記録](docs/devlog/2026-11-11-player-ui.ja.md)

準備中の「戻す」または Ctrl+Z で、盤面上の移動、回転、合成を一回取り消せます。吸収、凝結、破棄、開戦、読み込みを行うと取り消し履歴は消え、再起動後にも残りません。[操作の記録](docs/devlog/2026-11-08-mage-undo.ja.md)

```powershell
npm run game:mage
```

![魔法使いの遠征準備画面。Godotの自動操作による撮影](docs/devlog/screenshots/2026-11-12-mage-seven-poses-v1/preparation.png)

新しい遠征では、火・水・風の元素を一つずつ持った状態から始めます。元素を微光の術式と組み合わせて魔法を作ります。「レシピ」から16種類の組み合わせを確認でき、金色の枠は選んだ配方の合成先を示します。爆炎と火から熾陽の大槍、氷矢と風から霜嵐の四重輪、結晶核と風から隣の術式を速める疾風の結晶環を作れます。

![魔法の作り方の画面。Godotの自動操作による撮影](docs/devlog/screenshots/2026-11-12-mage-seven-poses-v1/recipes.png)

結晶核と水から月蛾の契約を作り、さらに水を重ねると月冠蛾、風を重ねると素早く一回攻撃する風月蛾に強化できます。契約一つにつき一体の使い魔が自動で攻撃し、三種類の合計で最大二体まで召喚できます。現在、敵は魔法使いだけを攻撃し、使い魔に独立した体力はありません。上位の配方を選ぶと、材料が足りる場合は先に基本の術式を作るよう案内されます。配方を選ぶだけでは材料を消費しません。基本の術式を作った後、上位の配方を再び選びます。

勝利後は「次の戦いへ」を押し、「凝結」で魔力の残滓を数に限りのある元素、術式、結晶核、法盾に変えられます。道具はクリックまたはドラッグで配置し、R で回転、スペースで開戦します。敵の攻撃を実際に軽減すると法盾が表示されます。従来の五戦セーブは元の敵・報酬・資源のルールを保ち、「最初から」で始めた遠征には七戦のルールが適用されます。

取得できる元素や凝結素材を選ぶと、右側に用途、残数、価格、現在の向きで占めるマスが表示されます。配置プレビューでは配置後の素材、残滓、法盾、影響を受ける術式を比較できます。配方帳は術式・使い魔・支援で絞り込めます。配置や合成を確定する前に資源は消費されません。戦闘後は「戦闘結果を見る」で攻撃元ごとのダメージと命中を確認できます。

遠征の保存先は `user://mage-campaign-run.json` です。従来の三敵から一体を選ぶ一戦版と予行演習は、`npm run game:mage:trial` で起動し、別の準備チェックポイントを使います。基本・月冠・風月の三種類の使い魔契約はありますが、敵は使い魔を攻撃しません。召喚を中心とする流派、奥術の循環、各職業三流派の完成は今後の課題です。[風の使い魔](docs/devlog/2026-11-10-mage-wind-familiar.ja.md) · [保存の記録](docs/devlog/2026-11-07-mage-campaign-save.ja.md) · [アニメーション計画](docs/ANIMATION_PLAN.md)

## 起動と準備

```powershell
npm run game
```

Godot エディターで `project.godot` を開いて F6 / F5 を押しても実行できます。F6 を使う場合は、先に `scenes/main.tscn` を開いてください。

1. Godot 4.7.2 .NET 版と .NET SDK 8.0.426 を用意します。SDK の ZIP を `.tools/dotnet/` に展開し、その直下に `dotnet.exe` がある状態にします。
2. `npm ci` でプロジェクト内の CLI をインストールします。
3. ターミナルで `$env:GODOT_BIN = 'Godot.exeのパス'` を設定します。または Godot .NET エディターの完全なパスを `.tools/godot-editor-path.txt` に書きます。このファイルは Git に含まれません。
4. 最初に `npm run godot:open` を実行し、C# のビルドと素材の取り込みを完了させます。その後は `npm run game` で森林試作、`npm run game:mage` で魔法使いの遠征を起動できます。

ゲーム本体は GDScript で作っています。C# と SDK は Godot MCP のエディタープラグイン用です。起動スクリプトが SDK の環境変数を子プロセスに渡し、SDK、NuGet パッケージとキャッシュは `.tools/` 内に置きます。エディター付属の Godot NuGet パッケージは `.tools/godot-nupkgs/` にコピーします。これらは Git に含めません。

### 森林試作の操作

| 操作 | 入力 |
| --- | --- |
| 移動・購入 | バッグへドラッグ。商品をクリックしてからマスをクリックしても配置可能 |
| 装備を見る | クリックまたはマウスを重ねる |
| 回転 | R |
| 合成 | 同じ装備・品質、または配方の材料を重ねる |
| 売却 | 選択後 D / Delete、または売却ボタン |
| 開戦・次の戦い・再開 | スペースまたは右下のボタン |
| 配置のキャンセル | 右クリック / Esc |
| 配方図鑑 | Tab |
| 音の切り替え | M |
| 勝利後の祝福を選ぶ | カードをクリック / 1、2、3 |
| 一時停止・メニュー | Esc。道具を持っている場合は先に配置をキャンセル |
| メニュー内の保存・読み込み | S / L |

最初は短剣二本を重ねて強化し、盾と月露草を購入できます。戦闘中、武器の下の金色の線が次の発動までの時間を示します。

### 森林試作の保存

準備、買い物、合成、祝福の取得後に自動保存し、開戦前の配置も保存します。戦闘中に終了して再開すると、その戦いの準備から始まり、戦闘の途中からは再開しません。クリアまたは敗北すると現在の遠征は終了します。

保存先は `user://emberpack-run.json` です。テスト、`--no-save`、スクリーンショットのモードは隔離され、プレイヤーの保存を読み書きしません。破損データや未対応の形式は先に通知し、新しい遠征には確認が必要です。保存失敗時は開戦せず、読み込み失敗時は現在のバッグを変更しません。

### 検証

```powershell
npm run game:test
```

バッグの配置、金貨、合成スペース、方向、祝福、フレームレートに依存しない戦闘、64ビットの乱数状態の保存、破損データと書き込み失敗の保護を検査します。マウスでの配置、五戦のクリア、保存・読み込み・再開も確認します。

当時の結果は、基本ルール **126項目**、保存 **148項目**、画面操作 **210項目**、美術資産の契約 **465項目**、合計 **949項目**でした。画面の検査は五つのウィンドウサイズ、マウス操作、再開時の消去、一時停止、同じ乱数種での戦闘結果の一致を含みます。1280×800、1440×960、1920×1080 の実行画面を確認していますが、他の DPI、環境、すべての美術品質の確認を意味するものではありません。
